How to use Shotgun

Setup

  • Open Setup (gear), enter the registration or runDisney URL, set Count.
  • Launch all once. Each browser gets its own profile and queue identity.

During the queue

  • At launch you often need to Control a window to click into the waiting room — tap a screenshot or Control.
  • Then watch: each card shows the live page status (waiting-room time, line position, messages).
  • Cards sort so Registration ready sessions rise to the top and glow magenta.
  • Tap the ready chip to show only sessions that need you right now.
  • Use the refresh icon or Auto-refresh to update previews. Check Queue code reads the live Queue-it state.

Important

  • Operate registration pages manually. Don't refresh queue windows unless the page tells you to.
  • Shotgun must keep running on Iris — the real browser windows open on that computer.
